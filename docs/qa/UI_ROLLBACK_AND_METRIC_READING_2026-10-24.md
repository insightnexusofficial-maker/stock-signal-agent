- 웹앱의 인라인 CSS를 UI 개편 전 `6917444`와 정확히 일치시켰다. 기존 배경·글자·카드·탭·종목 행·간격·모바일 규칙을 복구했다.
- 전역 덮어쓰기 CSS를 제거했다. 특히 헤더 우측 가로 배치, 44px 버튼 두 개를 추가한 종목 행, 모바일 두 줄 요약, 종목명 임의 음절 줄바꿈을 제거했다.
- 종목 행은 기존 `종목 / RSI·가격 / 별표` 3열이다. 추가 펼침 버튼은 없앴고 행 클릭·Enter·Space로 펼칠 수 있다. 갱신 때 펼침 상태와 키보드 초점을 유지한다.
- Study의 이번 폰트·굵기 변경도 원래 상태로 복구했다. 정량·사이클·이벤트 JSON은 건드리지 않았다.
- 설정의 밝은/어두운 화면, 기기별 푸시 on/off, 시장 자료 상태, 추가 거시 지표, Study 근거, 지표 값/그래프 팝업은 유지했다.
- 신규 요소만 별도 CSS를 적용한다. 밝은 테마의 기존 가이드 바로가기와 사이클 배지·추세 색은 밝은 배경에 맞춰 보완했다. 추가 거시 목록은 넓은 화면 2열, 640px 이하 1열이며, 새 컴포넌트에 `min-width:0`, 폭 제한, 단어 단위 줄바꿈을 적용했다. 기존 행 전체에 새 글자 크기나 폭을 적용하지 않는다.
- 접힌 제목에는 짧은 자료 상태만 둔다. 긴 설명은 펼친 내용에서 읽는다. 사이클 배지도 짧게 두고 근거 부족·상충·독립 검토 대기는 상세에 남긴다.

## 지표를 읽는 순서

데이터가 갱신되어 거시 버튼이 교체돼도 팝업을 닫으면 같은 지표 버튼으로 초점을 돌려준다.

목록에서는 `지표명·현재 값 → 비교 수치 → 한 문장 해석 → 관측 기준`을 보여준다. 팝업은 `무엇을 보나요 / 비교 기준 / 어떻게 읽나요 / 함께 확인할 점` 네 항목으로 통일한다. 출처와 수집 시각은 별도로 둔다.

| 지표 | 비교 기준 | 읽는 핵심 |
| --- | --- | --- |
| 미국 2년 금리 | 약 1개월 전 관측값, 변화는 %p | 시장의 단기 금리 부담 변화. 기준금리 결정 자체와 다르다. |
| 미국 10년 실질금리 | 약 1개월 전 관측값, 변화는 %p | 미래 이익을 현재 가치로 평가할 때의 부담과 이익 전망을 함께 확인한다. |
| 광의 달러지수 | 약 1개월 전 대비 % 변화 | 여러 통화에 대한 달러 강도. 원·달러 환율과 같은 방향인지 확인한다. |
| NFCI | 공식 통계 기준 0, 약 1개월 전 변화 | 0 위는 장기 평균보다 긴축적, 아래는 완화적. 수준과 방향을 구분한다. |
| 신규 실업수당 청구 | 최근 4주 평균, 가능하면 직전 4주 평균 | 한 주의 등락보다 고용 흐름을 확인한다. 단위는 청구 건수다. |
| 근원 CPI·PCE 지수 | 전월비, 전년 동월비, 생산자의 3개월 연율, 가능하면 직전 3개월 연율 | 지수 수준은 물가상승률이 아니다. 물가가 느리게 오르는 것과 물가 하락을 구분한다. |
| 실업률 | 바로 전 기준월 대비 %p | 고용·소비 흐름을 실업수당 청구와 함께 확인한다. |
| 기존 VIX·QQQ·KOSPI·환율 | 기존 5일 평균·20일 평균·전일 대비 값 | 기존 수치와 신호는 유지하고 팝업의 정의·비교·확인할 점을 보완한다. |

비교는 실제 관측 이력으로 계산한다. 일별·주별 지표의 약 1개월 비교는 현재 관측일 30일 전을 기준으로 8일 이내의 이전 관측값만 쓴다. 월간 비교는 정확히 이전 기준월/전년 같은 기준월을 쓴다. 전년비는 양수인 기준 지수가 있을 때만 계산한다. 직전 3개월 연율 비교는 7개 연속 월간 관측이 있을 때만 계산한다. 이전 4주 평균은 최근 관측일까지 이어지는 8개 연속 주간 자료가 있을 때만 계산한다.

자료가 부족하면 비교 자료 부족으로 표시한다. 날짜를 확인할 수 없거나 자료 상태가 확인 불가이면 현재 해석을 보류한다. 지연·만료·직전값은 직전 자료 기준이라는 점을 해석에 표시한다. 새 위험 임계값·위기 확률·매매 판정·보유 비중 조절 규칙은 만들지 않았다.

`%p`는 비율의 차이라는 예시를 제공한다. 연준의 2% 목표는 전체 PCE 연간 상승률에 대한 것이므로 근원 PCE 3개월 연율과 직접 동일시하지 않는다. 기업에 대한 확인 질문은 지표 정의를 보유 근거 점검에 연결한 설명이며, 공식 기관의 투자 권고가 아니다.

### 관측 공백

Codex Work 설정의 로컬 브라우저 제어가 비활성화되어 CUA 탭 연결이 거절됐다. 화면 열기 요청과 브라우저 제어 권한은 별개다. 따라서 이번 버전의 실제 스크롤·픽셀 렌더·모바일 스크린샷·전체 화면 overflow 검증을 완료했다고 주장하지 않는다. DOM 테스트는 CSS 레이아웃을 렌더하지 않는다. 320/390/768px 실화면 확인과 스크린리더에서 행 내부 별표 노출 확인은 남은 검증이다. 현재 생산자의 약 180일 이력에서는 월간 전년비·직전 3개월 비교가 자료 부족으로 생략될 수 있으며 정상 동작이다.

실제 푸시 등록 화면의 연결 오류도 이 변경에서 원인을 확정하거나 해결했다고 주장하지 않는다. 화면 복구를 위해 운영 승인·FCM 게이트를 우회하지 않았다. 민감 설정·브라우저 저장소·사용자 문서·계정 정보는 조회하지 않았다.
